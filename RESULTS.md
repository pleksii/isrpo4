## Команды для работы с проектом

### Запуск тестов

```bash
# Все тесты для прямоугольника
python3 -m unittest rectangle.py

# Все тесты для круга
python3 -m unittest circle.py

# Все тесты вместе
python3 -m unittest rectangle.py circle.py

# С подробным выводом
python3 -m unittest -v rectangle.py circle.py
```

### Работа с Git

```bash
# Просмотр истории коммитов
git log --oneline

# Просмотр изменений
git log --stat

# Детальная информация о коммите
git show <commit-hash>

# Публикация на GitHub (после создания репозитория)
git remote add origin <url-репозитория>
git branch -M main
git push -u origin main
```
