# Лабораторная работа №4: Unit-тестирование

## Описание проекта

Проект демонстрирует применение unit-тестирования для проверки корректности работы функций геометрических расчётов. Реализованы модули для работы с прямоугольниками и кругами, а также полный набор автоматизированных тестов с использованием фреймворка `unittest`.

## Функциональность

### Модуль `rectangle.py`

**Функции:**
- `area(length, width)` - вычисление площади прямоугольника
- `perimeter(length, width)` - вычисление периметра прямоугольника

**Формулы:**
- Площадь: `S = length × width`
- Периметр: `P = 2 × (length + width)`

**Количество тестов:** 12

### Модуль `circle.py`

**Функции:**
- `area(radius)` - вычисление площади круга
- `circumference(radius)` - вычисление длины окружности

**Формулы:**
- Площадь: `S = π × r²`
- Длина окружности: `C = 2 × π × r`

**Количество тестов:** 10

## Установка и запуск

### Требования

- Python 3.x
- Стандартная библиотека Python (unittest, math)

### Запуск тестов

#### Запуск всех тестов для прямоугольника:

```bash
python -m unittest rectangle.py
```

Или с подробным выводом:

```bash
python -m unittest -v rectangle.py
```

#### Запуск всех тестов для круга:

```bash
python -m unittest circle.py
```

#### Запуск всех тестов сразу:

```bash
python -m unittest rectangle.py circle.py
```

#### Запуск конкретного теста:

```bash
python -m unittest rectangle.RectangleTestCase.test_square_area
```

### Пример использования функций

#### Работа с прямоугольником:

```python
from rectangle import area, perimeter

# Вычисление площади прямоугольника 5x3
s = area(5, 3)
print(f"Площадь: {s}")  # Площадь: 15

# Вычисление периметра
p = perimeter(5, 3)
print(f"Периметр: {p}")  # Периметр: 16
```

#### Работа с кругом:

```python
from circle import area, circumference

# Вычисление площади круга радиусом 5
s = area(5)
print(f"Площадь круга: {s:.2f}")  # Площадь круга: 78.54

# Вычисление длины окружности
c = circumference(5)
print(f"Длина окружности: {c:.2f}")  # Длина окружности: 31.42
```

## Обработка ошибок

Все функции включают валидацию входных данных:

```python
# Попытка передать отрицательное значение
try:
    area(-5, 10)
except ValueError as e:
    print(e)  # Длина и ширина должны быть неотрицательными
```
